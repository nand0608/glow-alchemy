# Glow Alchemy

A mystical e-commerce web application built with React and Vite, featuring crystal jewellery, aromatherapy candles, gift hampers, bracelets, and spiritual healing session bookings.

## 🔮 Features
- **Header & Mega Menu**: Same layout with rich categories & dropdowns.
- **Hero Section**: Mystical banner featuring amethyst crystals, purple candles, and atmospheric glow.
- **Category Browse**: Responsive card grid for Crystal Jewellery, Candles, Hampers, Bracelets, Pendant Sets, and Session Bookings.
- **Features Bar**: Highlights for Free Shipping, Easy Returns, 100% Authentic Products, and 24/7 Support.
- **Custom Theme**: Luxury mystical purple palette (`#270e43`).

## 🚀 Getting Started
```bash
npm install
npm run dev
```
